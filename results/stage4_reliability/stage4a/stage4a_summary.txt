Stage 4A — Deployable uncertainty-aware reliability pipeline

COMP 895: Uncertainty-Aware Semantic Segmentation under Adverse Driving Conditions
Status: complete; stopped before Stage 4B.

Implementation
reliability_pipeline.py: reusable class, independent of dataset paths and GT.
run_reliability_pipeline.py: single-image CLI and numerical/visual output writer.
test_reliability_pipeline.py: five focused engineering unit tests, all PASS.

Public API (path or PIL.Image):
    from reliability_pipeline import ReliabilityPipeline
    pipeline = ReliabilityPipeline(threshold=0.10, uncertainty_method="calibrated_msp")
    result = pipeline.predict("/path/to/image.png")
The threshold above is an example engineering input, NOT a selected operating point.
Threshold is a required constructor/CLI argument; no implicit default is chosen.
Device defaults to CUDA when available; device="cpu" is also supported.
The module-relative temperature artifact path works independently of current working directory.
For mode reuse, infer_logits(image) returns (1,19,H,W) float32 logits;
predict_from_logits(logits, uncertainty_method=...) reuses them without another model pass.

Outputs
result['segmentation']: H x W uint8 canonical trainIds 0..18.
result['uncertainty']: H x W floating-point score; higher means less reliable.
result['confidence']: H x W maximum class probability, including entropy modes.
result['reliability_mask'] and result['accepted_mask']: same H x W boolean array.
result['rejected_mask']: boolean complement. result['metadata']: provenance/counts/coverage.
Acceptance is uncertainty <= threshold, including equality. Rejected pixels retain
original class IDs in canonical segmentation. Display-only magenta does not alter predictions.
Coverage includes every input pixel, with no GT-dependent valid-pixel filtering.
Risk is neither computable nor reported by this GT-free inference pipeline.

RGB -> processor 512 x 1024 -> eval/inference_mode -> native float32 logits
-> bilinear interpolation (align_corners=False) to original H x W
-> unscaled-logit argmax for canonical segmentation
-> raw softmax or frozen-temperature softmax -> uncertainty -> user-supplied mask.
Precision: float32 inference/interpolation; raw probabilities float32; calibrated probabilities float64.
MSP uncertainty = 1 - maximum class probability.
Entropy = -sum(p * log(max(p,1e-12))) / log(19), as in Stages 2–3.
Modes: raw_msp, calibrated_msp (engineering default), raw_entropy, calibrated_entropy.
No fit, calibration revision, threshold search, or GT loading occurs.
