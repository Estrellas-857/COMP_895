STAGE 5A: FROZEN-POLICY VALIDATION
1. Objective: evaluate the single frozen reliability policy without retuning on validation outcomes.
2. Dataset and population: all 406 ACDC adverse validation images, containing 841,881,600 total pixels, 790,712,012 semantic-valid pixels, and 51,169,588 ignored pixels.
3. Methodology: use full-resolution argmax of unscaled logits as the canonical prediction; define calibrated MSP uncertainty U = 1 - max softmax(z / T); accept U <= tau. Inference precedes offline ground-truth access. Errors and confusion matrices use train IDs 0–18 and ignore 255. ACDC invalid-region masks are distinct from semantic-ignore labels.
4. Configuration: fixed Cityscapes SegFormer-B0 revision 7a91500a7086b805eeb868719ea5542a3e0bdeb3; T = 2.124186626456894; tau = 0.386413580715649. Inference and bilinear interpolation use float32; calibrated probabilities use float64.
5. Metrics: valid coverage = (FN + TN) / (TP + FP + FN + TN); all-pixel coverage = accepted image pixels / all image pixels; accepted risk = FN / (FN + TN). TP means incorrect and rejected, FP correct and rejected, FN incorrect and accepted, and TN correct and accepted. Pooled statistics sum counts before division; they are not means of image or condition statistics. Undefined ratios are null.

STAGE 5B: DESCRIPTIVE RISK–COVERAGE COMPARISON
1. Objective: compare raw and calibrated MSP and normalized entropy over different rejection levels without selecting a new operating policy.
2. Dataset and population: the same 406 validation images and all their valid pixels, summarized by condition and pooled by summing histograms. Four methods x five populations x six requested coverages produce 120 checkpoints.
3. Methodology: use 1,000 equal-width bins over [0, 1] and int64 correct/error counts. Accept whole bins from low to high uncertainty. Omit zero-accepted points and preserve duplicate coverages caused by empty bins. Bins are [lower, upper), with the final bin including 1. Each checkpoint minimizes absolute coverage error; ties select the first ascending bin. Risk at zero coverage and ordering within a bin are not fabricated.
4. Configuration: raw MSP and raw normalized entropy use float32; variants calibrated with the global T use float64. Normalized entropy is -sum(p x log(max(p, 1e-12))) / log(19). Frozen tau remains unchanged. All methods use the same correctness labels from canonical raw-logit argmax.
5. Metrics: cumulative accepted errors / cumulative accepted valid pixels, plotted against cumulative accepted valid pixels / all valid pixels. At 100% coverage, every method's risk equals the exact baseline risk. No AURC is reported. The random-rejection reference line is the expected error prevalence, not a confidence interval.

2. Dataset and population: one Night Sky image, GOPR0356_frame_000363, and one Snow Terrain image, GOPR0122_frame_000364. These are individual examples, not whole-condition or whole-class populations.
3. Methodology: freeze inference outputs before opening ground truth. Define the target mask by the ground-truth class; divide missed target pixels into accepted and rejected sets; separately audit their predicted destination classes.
4. Configuration: the same frozen T, tau, and calibrated MSP; a descriptive high-confidence cutoff of 0.90; unchanged predictions from unscaled-logit argmax.
5. Metrics: target coverage = accepted ground-truth target pixels / all ground-truth target pixels; target error recall = rejected misses / all misses; remaining error fraction = accepted misses / all misses; accepted target risk = accepted misses / accepted ground-truth target pixels. High-confidence missed fraction divides by all missed target pixels, not by all high-confidence pixels. The rejection rate among correctly predicted target pixels is undefined when no target pixels are correct.

STAGE 5D: RUNTIME AND GPU MEMORY
1. Objective: characterize the cost of the baseline and final reliability pipelines on the same hardware, using the same timing boundaries.
2. Dataset and population: 20 RGB validation images, the lexicographically first five per condition; five warmups per pipeline; three timed repeats per image; 60 observations per pipeline. Repeats do not turn these 20 images into 60 independent images.
3. Methodology: paired alternating AB/BA execution, perf_counter wall-clock measurement, and CUDA synchronization before and after each timed region. Batch size is 1. Standard deviation uses ddof = 0; approximate FPS = 1,000 / mean milliseconds. Peak allocated GPU memory is reset per run; the reported peak is the maximum across 60 runs.
4. Configuration: NVIDIA RTX 3060; processor input 512 x 1,024; original output 1,920 x 1,080; model already resident. Inference and interpolation use float32; final scaling and softmax use float64. Validation checks inside the measured pipeline remain included.
5. Metrics and boundaries: both pipelines include preprocessing a predecoded PIL RGB image, transfer of inputs to the GPU, model execution, full-resolution bilinear upsampling, raw argmax, and transfer of a uint8 prediction to the CPU. The final pipeline also includes float64 temperature scaling and softmax, MSP, confidence transfer to the CPU, threshold comparison, and accepted/rejected masks. Both exclude RGB disk reading and decoding, model loading/downloads, artifact hashing, wrapper metadata, ground truth and evaluation metrics, plotting, and serialization. Memory is peak PyTorch allocated GPU memory, including the resident model; it is not reserved memory, total GPU usage, or system RAM.
