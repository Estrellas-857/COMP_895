VERIFIED MASTER RESULTS
Uncertainty-Aware Semantic Segmentation under Adverse Driving Conditions

Reading convention
This readable table set selects the important results. B_master_results.csv and B_master_results.json contain the full sourced ledger, including configuration and verification fields. Every ledger row specifies metric, population, configuration, value, unit, exact source file, source field, row selector and interpretation. Numerical table cells below are rounded only for display; the source CSV/JSON fields and ledger preserve their saved precision. Percent columns multiply saved fractions by 100. A percentage-point difference is not a relative percentage change. Undefined values remain undefined.

Population and metric boundaries
Full adverse validation contains Fog 100, Rain 100, Snow 100 and Night 106 images. Paired baseline validation contains 50 pairs per non-Night condition and 53 Normal–Night pairs. Global fitting uses 802 training images; threshold selection uses 798 different training images. Controlled transfer fits use 101 matched training pairs. The paired extension evaluates 53 images per domain, not the full 106-image Night subset. Each image uses its own semantic GT; corresponding views are not pixel aligned. Exact population sources appear in the tables below.

The baseline and final policy use fixed canonical predictions. Historical Stage 2 and Stage 3D raw correctness uses softmax argmax; documented one-pixel differences from raw-logit argmax are retained rather than silently replaced. Valid means semantic trainId 0–18; ignore 255 is excluded from semantic metrics. Pooled pixel metrics sum counts/statistics before division. ECE uses 15 equal-width confidence bins with absolute gaps; signed mean-confidence minus accuracy is a different measure. AUROC and AP use error-positive score histograms in Stages 2/3. AP sums precision times recall increments rather than trapezoidal PR area. Stage 5B uses every valid pixel in 1,000 score bins. Extension risk curves and right-step AURC use shared weighted samples of 8,192 valid pixels per image; neither gives exact full-resolution ranking. Fixed operating counts are exact and full resolution.

CLAIM BOUNDARY
The strongest supported claim is that substantial NLL/ECE improvements do not consistently yield practically meaningful improvement in error ranking or risk at comparable coverage for this fixed model and these populations. Global calibration does help some original ranking metrics. No statistical significance, exact full-resolution AURC, semantic correction, untouched-validation guarantee, independent-pixel evidence, new calibration algorithm or downstream safety guarantee is established. See G_consistency_and_claim_audit.txt.
