Protocol and execution order
  1. Verify GPU access, freeze exact manifests, objectives, and source hashes.
  2. Reuse 101 Night fitting caches and generate 101 Normal fitting caches.
  3. Fit NightPair, NormalPair, and equal-domain Mix from training data only.
  4. Generate the 106 paired validation caches once.
  5. Evaluate five temperatures on every validation image using its own GT.
  6. Require saved Stage 1 confusion and Stage 5 count parity before reporting.
  7. Generate the report and verify all protected historical file hashes.

Metric interpretation
  NLL is in nats. CSV proportions are in [0,1]; findings labels percentages.
  ECE uses 15 equal-width bins. Signed gap is confidence minus accuracy.
  Valid coverage uses semantic GT 0–18. All-pixel coverage includes ignored GT.
  Accepted risk is wrong accepted valid pixels / accepted valid pixels.
  High-confidence error rate is wrong valid pixels with confidence >=0.90 /
  all valid pixels with confidence >=0.90. error_high_conf_fraction instead
  divides by all semantic errors. Undefined ratios are empty CSV cells/null.
  Fixed-tau comparisons can have different coverages. Compare error ranking
  using the shared-sample 50/60/70/80/90% checkpoints and report actual coverage.
  Sampling is uniform within image, weighted by valid population/sample count.
  AURC and checkpoint risks are estimates, not exact full-population ranks.
  Raw probabilities follow the historical float32 convention; calibrated
  probabilities use float64. Very small ranking differences may include
  numerical confidence saturation or quantization effects.
  Normal and Night references are scene pairs, not pixel-aligned images.
  Validation was previously explored and has only two sequence IDs. Pixels
  and neighboring frames do not supply independent statistical replications.
