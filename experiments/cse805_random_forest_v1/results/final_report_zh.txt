CSE 805　用随机森林预测恶劣天气下的语义分割错误

在同一批 17 个留出组上，RF + Class 取得六种方法中最高的平均 AUROC 和 AP、最低的平均 AURC，以及最低的约 80% 覆盖率接受错误率。相对 LR + Class，整体接受错误率从 7.665% 降到 7.523%。Fog 和 Snow 贡献了这项收益。Night 的变化主要出现在低覆盖率，约 80% 处两版类别 LR 仍略好。

实验怎么做

沿用 ACDC 的 Fog、Night、Rain、Snow 各 400 张标注图像。原项目另有 406 张验证图像，独立于本次 17 组协议。外层每次留出一个文件名分组，用其余 16 组训练。每张训练图用相同的 512 个有效像素，按抽中概率的倒数加权。内层用原来的三个分组验证折比较深度 8 和 14，以验证 AP 的均值选择。森林固定 32 棵树、每叶至少 64 个样本、随机种子 805。17 折都选中了深度 14。

RF 与 LR + Class 使用相同的信息，即冻结 SegFormer-B0 的 MSP、归一化预测熵、前两类概率差，以及预测类别的 19 维独热编码。真实类别只用于定义和核对错误标签。六种方法评估相同的 3,059,663,748 个有效像素，其中 523,653,212 个分割错误。分别在各留出组评分后等权平均，故总体结果中 6 个 Fog、3 个 Night、3 个 Rain、5 个 Snow 组各占一票。全像素错误率为 17.115%，逐组错误率的等权均值为 15.290%。

接受错误率是保留像素中原分割预测错误的比例。主分析使用原方案的 100,000 个分数箱、最接近 80% 的整箱覆盖率和右端阶梯 AURC。RF 在 16/17 个组的主操作点优于 MSP，平均少 0.871 个百分点。相对两版类别 LR，RF 各胜 11/17 组，平均分别少 0.143 和 0.143 个百分点。逐一排除一个组后，RF 相对 LR + Class 的平均改善仍在 0.101–0.176 个百分点之间，这是对组权重的描述性敏感性检查。

每组各保留有效像素的 10%。目标落在同一分数箱内时，按相同比例从该箱均匀选取，表中给出预期接受错误率。每一行比较相同数量的像素。

三组的相同接受预算合计 74,391,824 个像素。RF 预期接受约 182.34 万个错误，LR + Class 为 1,584.71 万，交互 LR 为 1,619.54 万，MSP 为 58.09 万。跨组相加的像素计数会给较大组更多权重，因而与三组等权错误率回答不同的问题。10% 时 RF 在三个组都改善了类别 LR 的排序，三个组里 MSP 都更可靠。在更严格的 1% 预算上，gopro_0397 的 RF 错误率达 4.552%，高于 LR + Class 的 1.529% 和交互 LR 的 1.625%。

RF 在 10% 附近给大量像素相同的分数。若只接受完整分数箱，gopro_0351、0376、0397 实际分别保留了 18.761%、3.501%、1.400%，记录到的错误分别为 869,881、833,967、132,321。三组的分母不同，直接相加这些错误无法衡量相同预算下的收益。用留出图像保存的核查样本、原始分数和与标签无关的同分顺序，得到 2.613%、2.869%、1.658%。其中 10% 边界上真正同分的像素权重分别占该组 17.55%、21.95%、23.38%。

在同一份 10% 核查样本中，LR + Class 接受的错误里，预测为植被的占比分别为 83.7%、93.7%、96.3%。RF 降到了 4.5%、44.4%、14.7%，接受像素中预测为道路的占比则达到 88.5%、64.8%、86.0%。这些差异在每个留出组内部都存在。它们描述了两类模型对像素排序的变化，仍不足以证明某个树分裂是改善的原因。

放眼整条 Night 曲线，RF 的 AP 为 0.6377，高于 MSP 的 0.6318。RF 的 AUROC 为 0.8160、AURC 为 0.13565，MSP 分别为 0.8174 和 0.13266。在 Night 选择方法时，应区分需要尽可能纯净的低覆盖像素集，还是希望在大部分像素上检测错误。

AURC 对同分规则的敏感性

对同一批留出核查样本和权重，六种方法统一比较 1 万、10 万、100 万个分数箱，以及按原始分数整组接受、按与标签无关的次序拆分原始同分这五种规则。RF 的 17 组平均 AURC 为 0.04100–0.04113，在五种规则下均为最低。在 Night，RF 平均为 0.13615–0.13718，MSP 为 0.13312–0.13320，两版类别 LR 均高于 RF。这一核查保留了全像素主分析中的相对结论，未用抽样结果替换主指标。

部署阈值与适用范围

约 80% 的主结果是回顾性比较。把各外层训练组上设定的 RF 阈值直接迁移到对应留出组后，实际覆盖率平均为 81.743%，组间范围 66.248%–91.261%，平均接受错误率为 7.334%。Night 实际平均只覆盖 67.731%，接受错误率为 19.895%。这组数值与各方法保留相同数量像素时的错误率应分开解释。

17 折合计的训练和模型选择用时约 261 秒。复用原生 logits 后，全像素评估合计约 294 秒，其中 RF 评分约 41 秒，含数据传输和首次编译。耗时取自各折日志，本次没有在统一硬件路径上比较六种方法的部署延迟。每张图的 8,192 个保存样本均与 scikit-learn 的森林分数逐个核对，共 13,107,200 个。

本次模型设置在 RF 训练前固定，但决定加入 RF 时已看过先前 Night 分析，因此属于探索性扩展。文件名分组仅作为录制来源的保守代理，Night 只有三个组。新路线或独立采集的夜间数据才能进一步检验这些差异。所有方法共享同一分割输出，测量的是错误预测和像素选择能力。
